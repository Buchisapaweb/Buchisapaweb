# Frontend BuchiSapa

El `index.html` público está deliberadamente en la raíz del proyecto. Esta carpeta contiene el código fuente organizado del cliente y del panel administrativo.

- `src/pages/html`: páginas completas del cliente.
- `src/components/html`: fragmentos HTML reutilizables.
- `src/styles`: CSS del cliente.
- `src/scripts`: JavaScript del cliente.
- `src/assets/images`: imágenes y recursos visuales.
- `src/admin`: código fuente del panel administrativo.
