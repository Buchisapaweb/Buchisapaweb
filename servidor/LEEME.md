# Servidor Backend BuchiSapa

Módulos y servicios de backend para la aplicación BuchiSapa:
- `base-datos/`: Consultas SQL y gestión de usuarios, pedidos, inventario y catálogo.
- `intermediarios/`: Middlewares de autenticación (JWT y tokens de sesión de administrador).
- `servicios/`: Servicios de correo electrónico y verificación de códigos.
- `utilidades/supabase/`: Clientes y configuración de acceso a Supabase.
