# Categorías BuchiSapa

Se conservan las 10 categorías oficiales para el catálogo del cliente:
1. Alitas
2. Bebidas
3. Broaster
4. Hamburguesas
5. Infusiones
6. Platos Amazónicos
7. Refrescos
8. Salchipapas y Salchibroasters
9. Adicionales
10. Promociones

El panel administrativo queda deliberadamente vacío en esta etapa. Los datos del catálogo se conservan para la página cliente y para su futura gestión desde el Admin.
